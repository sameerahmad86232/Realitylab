# Reality GT generated assets

Two original concept images were generated during this task with the available image-generation tool:

- `frontend/src/assets/reality-gt.png`: titanium-silver electric grand tourer, three-quarter studio view.
- `frontend/src/assets/reality-gt-plan.png`: matching overhead concept illustration generated using the first image as reference.

The design brief requested an original, unbranded coupe with forest-green studio lighting and subtle lime accents. The original generated outputs remain in `/workspace/generated_images`.

These are AI-generated visual assets, not photographs of an existing vehicle, verified engineering drawings, measured CAD, or evidence of working Meta model integration. The app labels the study as a curated sample and separates concept features from unverified internal hypotheses. The hand-authored wireframe is illustrative and not to scale.
