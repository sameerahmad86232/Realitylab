# Three-minute demo: RealityLab

The existing frontend at commit `39141b3` predates the supplied October 27 building
period. Disclose it as the presentation baseline. Identify the backend, actual
Meta/Baseten inference, validated general-object output, editable evidence map,
review notebook, deterministic physics tools and report workflow in the event
change set. Preserve the real commit history; do not backdate contributions.
Check the organizer's final eligibility interpretation before submission.

## 0:00–0:20 — The problem

"A photo can suggest how something works. RealityLab helps us separate what we
can see, what a model proposes, and what we can actually test."
Show the explorer. The decorative gear studio is illustrative and separate from
photo analysis; avoid presenting it as reconstructed geometry.

## 0:20–1:00 — Fresh input, real Meta inference

Upload a fresh, well-lit photo of a real hand-powered external gear pair. Show
the provider-sharing disclosure, submit, and wait for the real result. Display
actual model provenance. Do not replace a failed or delayed live call with an
unlabeled recording. A prepared CC0 mouse/chair photo can demonstrate general
object exploration, but it cannot replace the physical experiment below.

## 1:00–1:35 — Inspect and correct the evidence

Select a component in the map and its image marker. Correct an inaccurate label
or marker, show the retained original model suggestion, and add a review note.
Point out a hypothetical connection or unknown. Show one follow-up notebook
entry based on an observation you actually make. A user review is self-reported.

## 1:35–2:25 — Predict, measure, compare

For the physical gear pair, independently count and confirm the two gears.
For a 12:24 pair, one input turn predicts half a turn in the opposite direction.
Turn the real input slowly and record the actual follower direction and turns.
Enter that measurement and show the declared-tolerance comparison. Include a
real discrepancy if one occurs. The UI's sample calculation is not evidence of
a physical experiment; a pre-rendered 3D animation is not a measurement.

## 2:25–3:00 — Take away the evidence

Download the readable report and photo-free JSON. Show corrected claims, original
model evidence, user notes, model provenance and numerical assumptions. End with
the public product URL and public repository. Explain the limited numerical
models and current uncertainty on unfamiliar or occluded objects in one sentence.

## Submission checklist

- Public repository, deployed HTTPS product, accessible three-minute video.
- All contributors named, maximum four according to the supplied guide.
- Clear identification of work built during the event versus pre-existing UI.
- Credit Meta's actual model, Baseten inference and third-party libraries/assets.
- Avoid claiming universal recognition, automatic CAD, validated strength or
  reconstruction. Do not claim the physical experiment was completed until done.
- The supplied guide lists simple image analyzers as an anti-project. Demonstrate
  the correction → test → measurement comparison loop; breadth or visual polish
  alone does not establish eligibility or a winning entry.
